# M3 A/B：「诊断 → 对策」提示有没有用

- 日期：2026-10-22
- 设计：同一批 24 题（`--select medium --sample 24`）、同一环境、1 轮模型修复，
  唯一变量是 `--hints`（ADR-0006）
- 记录：`runs/m3-hints-off.jsonl`、`runs/m3-hints-on.jsonl`

## 结果

| | 级联（第 0 轮） | 加模型后 | 净变化 |
|---|---:|---:|---:|
| **A：无提示** | 4/24 = 16.7% | 12/24 = **50.0%** | +8 |
| **B：有提示** | 4/24 = 16.7% | 13/24 = **54.2%** | +9 |

配对比较（同样的 24 题）：

| | 题数 |
|---|---:|
| B 相对 A **新增** | 2（`algebra_amgm_faxinrrp2msqrt2geq2mxm1div2x`、`algebra_sqineq_36azm9asqle36zsq`） |
| B 相对 A **丢失** | 1（`mathd_algebra_422`） |
| 净变化 | **+1** |

成本：输入 token 从 7,841 涨到 9,721（**+24%**），输出基本不变（3,073 → 2,948）。

## 结论：**没有可靠效果**

n=24 上 +1 题完全可能是噪声；而且为了这 +1 多付了 24% 的输入 token。
更值得注意的是**它丢掉了一道原本能做出的题**——说明提示会干扰模型，
让它偏离自己本来会走的路。

ADR-0006 事先写了判据：「如果 A/B 显示无效，不要硬推」。所以：

- **`--hints` 保持默认关闭**，不并入主流程；
- 这张表**不作为 M3 的成果**，只作为一次负结果记录。

## 更有价值的线索

A/B 没赢，但 M2 里那个具体案例仍然有效：模型靠「`max_rec_depth` → `set_option
maxRecDepth 10000 in`」救回了一道题。问题不在**这个知识**，而在于**用 prompt 传递它**。

所以下一步应该是把它做成**确定性补救**，而不是提示：

```text
L0 级联失败（且诊断是 max_rec_depth / exponent_threshold）
  → 用同一套 tactic 再过一遍，但 preamble 加上
       set_option maxRecDepth 10000
       set_option exponentiation.threshold 10000
  → 完全不需要模型，零 token 成本，可离线复现
```

要验证这个，需要：

1. 一个能把额外 option 注入 preamble 的开关（`MINIF2F_EXTRA_OPTIONS` 或 `--extra-opt`）；
2. 拿 M1 里那 7 道 `max_rec_depth` 的题（`amc12a_2003_p1`、`mathd_numbertheory_109/198/236/43/543/690`）
   跑一次对照。

如果这 7 题里能救回一半，那就是**不需要模型**的净收益，比在 prompt 上折腾划算得多。

## 方法学备注

- 单次运行、n=24、无序贯重跑，**不能**下「提示无效」的强结论；只能说「这点样本上没看到收益」。
- 两臂的模型调用轮数都是 1，token 差异来自提示本身。
- 这个 A/B 也顺带说明：**在 M2 这种「模型本来就能解 50%」的设定里，
  任何 prompt 微调的效应都容易淹没在单题方差里**。要么扩样本，要么找确定性收益。
